# JBL Headphones App

An unofficial browser-based tool for inspecting and controlling supported JBL headphones from a PC.

## Key features

- Read mapped settings and inspect Bluetooth protocol data.
- Back up readable settings and restore selected compatible values.
- Supports JBL TUNE 720BT and a reference mapping for 780NC.

## Get started

Download the ZIP from Releases and run `START JBL Headphones App.bat`. The 780NC mapping was not verified on physical hardware; changing undocumented settings can affect the device.
