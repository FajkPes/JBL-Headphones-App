# Release notes

## v1.0.0

- First public, cleaned release of the JBL Headphones App and mapping guide.
- English is the default and audited UI language for both supported models.
- Added an English dependency-aware launcher and localhost server output.
- Added English backup and exploration ZIP filenames and reports.
- Preserved compatibility with older `zaloha.json` backup archives.
- Included the 216-test protocol and safety suite plus a rendered UI audit.
- Excluded APK files, decompiled sources, captures, archives, and bundled
  reverse-engineering tools from the public package.
